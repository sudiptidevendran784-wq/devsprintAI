
# MessageMatch Enterprise

AI-powered ad-to-landing-page message matching and regulatory compliance auditing tool.

## Features

- Advertisement claim extraction and analysis
- Ad-to-landing-page message matching
- Regulatory compliance risk checks
- AI-assisted copy variant generation
- PDF, Excel, and HTML report exports
- SQLite audit history
- Streamlit web interface

## Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Pillow

## Run Locally

Install the required dependencies:

```bash
python -m pip install -r requirements.txt
```

Start the application:

```bash
python -m streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## Run Tests

```bash
python test_suite.py
```

## Disclaimer

Compliance results are automated screening estimates and should be reviewed before making legal or regulatory decisions.
